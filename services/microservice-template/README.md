# Microservice Template

Folder ini berisi starter template dasar untuk microservice Node.js + TypeScript.

Gunakan sebagai basis untuk service berikut:
- identity
- catalog
- inventory
- order
- payment
- notification

Langkah cepat:
1. copy `microservice-template` ke direktori service baru.
2. ganti `name` di `package.json`.
3. implementasikan `src/index.ts` dan endpoint domain.
4. build image dengan `Dockerfile`.
